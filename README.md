# LaSec-Laser-Based-Intrusion-Alert-System



LaSec is a laser-based intrusion detection system that uses an Arduino Uno, an LDR (Light Dependent Resistor), and a laser beam to detect unauthorized entry. When the laser beam is interrupted, the system immediately activates a buzzer to provide a real-time intrusion alert. The circuit was designed, tested, and implemented as a hardware prototype with a custom PCB for improved reliability.

---

## 📌 Features

- Laser beam interruption sensing
- LDR-based intrusion detection
- Real-time buzzer alert
- Threshold-based detection logic
- Custom PCB implementation
- Hardware prototype

---

## 🛠 Components Used

- Arduino Uno
- LDR (Light Dependent Resistor)
- Laser Module
- Buzzer
- Resistors
- LEDs
- Custom PCB
- Connecting Wires

---

## ⚙️ Working Principle

A laser beam is continuously directed toward an LDR. Under normal conditions, the laser keeps the LDR illuminated. When an object interrupts the beam, the change in LDR resistance is detected by the Arduino, which triggers the buzzer to indicate a possible intrusion.
